# SPAN poster companion page

Companion web page for the poster "Multiscale Computational Framework for Sulfurized Polyacrylonitrile" (AIChE Annual Meeting 2026). Static site: `index.html`, `style.css`, `script.js`, `interactive.js`, `figures/`.

Interactive views in sections 4 to 6 read JSON files from `data/`; see `data/README.md` for the formats. They stay hidden until the files exist.

Served by GitHub Pages from the `main` branch.
